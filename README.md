# ai-localization-pipeline

Инструмент для автоматизированной локализации (перевода) игровых модов и файлов конфигураций с помощью локальных LLM (через Ollama). Поддерживает форматы JSON, XML и Plain Text.

## 🚀 Features

* **Мультиформатность:** Автоматическое определение и корректная сборка структур JSON, XML и обычного текста.
* **Умное маскирование (Tokenization):** Служебные теги, ключи и переменные заменяются на токены (text_0, xml_tag_1), что исключает поломку синтаксиса кода нейросетью.
* **Чанкование (Chunking):** Разбивка больших файлов на контролируемые порции, чтобы не превышать лимиты контекстного окна LLM.
* **Глоссарии:** Динамическая поддержка словарей терминов (имена, предметы, лор) для сохранения единообразия перевода.
* **Live SSE Streaming:** Отображение прогресса перевода и логов в реальном времени прямо в браузере.
* **Локальность:** Работает полностью на вашем железе, не отправляя данные на сторонние серверы.

## 🛠️ Requirements

* **Python:** 3.10+
* **Ollama:** Ollama: Установленный и запущенный Ollama с моделью (рекомендуется deepseek-r1:14b или mistral-nemo:12b).

## 📦 Installation

### 1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/NekitSan/ai-localization-pipeline.git
cd ai-localization-pipeline
```

### 2. **Создайте и активируйте виртуальное окружение:**

*(Для Linux/WSL: если команда `venv` не найдена, установите пакет: `sudo apt install python3-venv -y`)*

```bash
python -m venv .venv
source .venv/bin/activate  # Для Linux/Mac/WSL
# или .venv\Scripts\activate для Windows
```

### 3. **Установите зависимости:**

```bash
pip install -r requirements.txt
```

### 🖥️ System Requirements (Минимальные требования)

Для комфортной работы пайплайна (особенно при переводе больших файлов) рекомендуется:

* **RAM:** 16 GB (система + одна локальная модель).
* **VRAM (GPU):** 8 GB (для квантованных версий моделей уровня 12B-14B).
* **Disk:** ~15–20 GB свободного места (под установку Ollama и веса моделей).

### 🧠 Tested Models (На чем тестировался проект)

Проект прошел тестирование на следующей связке локальных моделей (указываются в `.env`):

* `deepseek-r1:14b` — использовалась как основная модель для качественного перевода и рассуждений.
* `mistral-nemo:12b` — отлично показала себя в роли быстрой альтернативы для перевода.

Вы можете указать любую другую модель в `.env`, главное — чтобы она поддерживала режим `format: "json"` в Ollama для стабильного парсинга ответов.


## ⚙️ Configuration

Перед запуском скопируйте .env.example в .env и настройте параметры:

### 1. `.env`

В этом файле хранятся базовые настройки ИИ:

```env
OLLAMA_API_URL=http://localhost:11434/api/chat
MODELS=deepseek-r1:14b,mistral-nemo:12b,glm-4.7-flash:latest
CHUNK_SIZE=12
```

### 2. llm/prompts/system_prompt.txt

Здесь лежит базовый системный промпт для модели. Вы можете настроить его под конкретную игру (например, указать стилистику перевода).

### 3. llm/glossaries/

Папка для словарей. Создайте файл base.json или свой собственный, чтобы обучить модель специфичным терминам. Пример:

```json
{
  "Steel Ingot": "Стальной слиток",
  "Power Armor": "Силовая броня"
}
```

## 🏃‍♂️ Running the App

Запустите приложение командой:

```bash
python run.py
```
